Setup

  1. Install Custara AP and update the Apps list (Odoo 18, self-hosted or Odoo.sh).
  2. Settings → Accounting → Custara AP: API URL https://custara.xyz and a Custara Partner API key from Developers.
  3. Open a vendor bill and click Send to Custara, or post the bill and wait for sync.
  4. Approve and pay in Custara. The payment writes back onto that bill.

Odoo Online can skip the module and use Custara → Connectors with a JSON-RPC API key. Demo data only: testnet.custara.xyz.
